Mellea is a Python library for building reliable generative AI applications with Granite. Rather than chaining ad-hoc prompts, developers write structured generative programs — Python functions where LLM operations are governed by type annotations, validation requirements, and automatic repair mechanisms. Mellea's core loop is Instruct, Validate, Repair: every LLM response is checked against developer-defined requirements before it leaves the system, and failures are automatically fed back to the model for retry using strategies like rejection sampling and majority voting.

Mellea provides first-class support for streaming, async operations, multi-turn chat contexts, and tool-based agents. It integrates with multiple inference backends including Ollama, OpenAI, AWS Bedrock, IBM watsonx, and HuggingFace, and works directly with the Granite Libraries' LoRA adapters for capabilities like requirement checking, hallucination detection, and guardian safety evaluation.
