This demo application combines several IBM technologies into a real-time voice assistant running live at IBM THINK 2026. Audio from the user's microphone flows through WebRTC into a processing pipeline. The Granite Speech model handles speech-to-text, converting the user's spoken words into transcripts. Those transcripts are passed to Mellea, which manages the chat context and runs generation against a Granite language model. Mellea streams tokens at sentence granularity for low-latency responses, and can optionally run Best-of-N parallel generation with Granite Switch requirement_check intrinsics — using LoRA adapters from the Granite Libraries — to validate that each response meets conversational tone, formatting, and content requirements before it leaves the system. The validated text is then sent to the IBM Watson TTS service for speech synthesis, and the resulting audio streams back to the user's browser over WebRTC.

The result is an end-to-end voice conversation powered entirely by IBM Granite models and tooling: Granite Speech for understanding, Granite Switch and Granite Libraries for validated generation via Mellea, and IBM Watson TTS for natural-sounding responses.
